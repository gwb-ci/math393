Definitin of a Ring

A nonempty set \(R\) is a ring if it has two closed binary operations, addition and multiplication, satisfying the following conditions.

  1. \(a+b=b+a\) for \(a,b\in R\).
  2. \((a+b)+c=a+(b+c)\) for \(a,b,c\in R\).
  3. There is an element \(0\) in \(R\) such that \(a+0=a\) for all \(a\in R\).
  4. For every element \(a\in R\), there exists an element \(-a\) in \(R\) such that \(a+(-a)=0\).
  5. \((ab)c=a(bc)\) for \(a,b,c\in R\).
  6. For \(a,b,c\in R\), \(a(b+c)=ab+ac\) and \((a+b)c=ac+bc\).

Keeping track of things in rings

Not only are the two operations but there can be many flavors or rings.

Many times the hard part of ring theory is keeping track of which properties a given ring has. Each property it has is a tool we can use for computations.

Notes on multiplication

  • Multiplication does not need to be commutative
  • Not every element needs to have a multiplicative inverse.
  • Even worse, we don’t even need an identity element for multiplication
  • Cancellation law does not need to hold

More notes on multiplication

  • If multiplication is commutative, \(ab=ba\) for all \(a\) and \(b\) the ring is a commutative ring.
  • If the ring has an idenity \(1\) where \(1\cdot a = a= a\cdot 1\) the ring is a ring with idenity.
  • If an element \(a\) has an inverse \(a \cot a^{-1}=a \cot a^{-1}\) then \(a\) is a unit.
  • If the product of two non-zero elements is zero \(a\cdot c =0\) they are zero-divisors.
  • If every non-zero element has an inverse, then the ring is a division ring

Examples of subrings with out identities

For an integer \(n\geq2\), consider \(n\mathbb Z\subseteq\mathbb Z\).

  • \(na+nb=n(a+b)\in n\mathbb Z\).
  • \(-(na)=n(-a)\in n\mathbb Z\).
  • \((na)(nb)=n(nab)\in n\mathbb Z\).
  • Associativity, commutativity of addition, and distributivity are inherited from \(\mathbb Z\).

An identity \(e\in n\mathbb Z\) would satisfy \(en=n\), forcing \(e=1\notin n\mathbb Z\).

Thus \(2\mathbb Z\), \(3\mathbb Z\), and \(7\mathbb Z\) are subrings without identities.

Some Types of Rings

  • Ring with unity or identity: There is an element \(1\in R\) such that \(1\neq 0\) and \(1a=a1=a\) for each element \(a\in R\).
  • Commutative ring: \(ab=ba\) for all \(a,b\) in \(R\).
  • Division ring: A ring with an identity in which every nonzero element is a unit.
  • Field: A commutative division ring.

Ur-Examples of commutative rings and fields

  • \(\mathbb Z\) is a commutative ring with identity \(1\).
  • If \(ab=0\) for integers \(a\) and \(b\), then \(a=0\) or \(b=0\).
  • The only units in \(\mathbb Z\) are \(1\) and \(-1\).
  • \(\mathbb Z\) is not a field: \(2\) has no multiplicative inverse in \(\mathbb Z\).
  • \(\mathbb Q\), \(\mathbb R\), and \(\mathbb C\) are fields under ordinary addition and multiplication.

Zero Divisors, Integral Domains, and Cancellation Law

A nonzero element \(a\) in a commutative ring \(R\) is called a zero divisor if there is a nonzero element \(b\) in \(R\) such that \(ab=0\).

A commutative ring \(R\) with identity is called an integral domain if, for every \(a,b\in R\) such that \(ab=0\), either \(a=0\) or \(b=0\).

  • \(\mathbb Z\) is an integral domain.
  • \(\mathbb Z_{20}\) is not an integral domain: \(3\cdot4=0\).
  • An integral domain has no zero divisors.

If \(ac=bc\) and \(c\neq0\) in an integral domain, must \(a=b\)?

Proposition 16.1.8

Let \(R\) be a ring with \(a,b\in R\). Then

  1. \(a0=0a=0\);
  2. \(a(-b)=(-a)b=-ab\);
  3. \((-a)(-b)=ab\).

Proof of 16.1.8

  • \(a0=a(0+0)=a0+a0\); hence, \(a0=0\). Similarly, \(0a=0\).
  • \(ab+a(-b)=a(b-b)=a0=0\); consequently, \(-ab=a(-b)\). Similarly, \(-ab=(-a)b\).
  • \((-a)(-b)=-(a(-b))=-(-ab)=ab\).

Subrings

A subring \(S\) of a ring \(R\) is a subset \(S\) of \(R\) such that \(S\) is also a ring under the inherited operations from \(R\).

  • The ring \(n\mathbb Z\) is a subring of \(\mathbb Z\).

  • Even though the original ring may have an identity, we do not require that its subring have an identity.

  • We have the following chain of subrings:

    \(\mathbb Z\subset\mathbb Q\subset\mathbb R\subset\mathbb C\).

Proposition 16.1.10 - Subring Test

Let \(R\) be a ring and \(S\) a subset of \(R\). Then \(S\) is a subring of \(R\) if and only if the following conditions are satisfied.

  1. \(S\neq\emptyset\).
  2. \(rs\in S\) for all \(r,s\in S\).
  3. \(r-s\in S\) for all \(r,s\in S\).

Proof of 16.1.10

  • Choose \(s\in S\). Why does \(s-s\) show that \(0\in S\)?
  • For \(r\in S\), why is \(-r\in S\)?
  • How does subtraction closure imply addition closure?
  • Which remaining ring axioms are inherited from \(R\)?

Quaternions

Let \(\mathbb H\) consist of elements of the form \(a+b\mathbf i+c\mathbf j+d\mathbf k\), where \(a,b,c,d\) are real numbers.

The ring \(\mathbb H\) is called the ring of quaternions.

  • Add by combining corresponding coefficients.
  • Multiply by distributing and using the relationships between \(\mathbf i\), \(\mathbf j\), and \(\mathbf k\).

Try it: Compute \((1+2\mathbf i-\mathbf j)+(3-\mathbf i+2\mathbf k)\).

Quaternion Multiplication

The generators satisfy the following relations:

  • \(\mathbf i^2=\mathbf j^2=\mathbf k^2=-1\).
  • \(\mathbf i\mathbf j=\mathbf k\).
  • \(\mathbf j\mathbf k=\mathbf i\).
  • \(\mathbf k\mathbf i=\mathbf j\).
  • \(\mathbf j\mathbf i=-\mathbf k\).
  • \(\mathbf k\mathbf j=-\mathbf i\).
  • \(\mathbf i\mathbf k=-\mathbf j\).

Try it: Compute \((1+\mathbf i)(1+\mathbf j)\).

Quaternions Are Noncommutative

Compare the products:

  • \(\mathbf i\mathbf j=\mathbf k\).
  • \(\mathbf j\mathbf i=-\mathbf k\).

Therefore, multiplication in \(\mathbb H\) is not commutative.

Try it: Expand and compare:

  • \((1+\mathbf i)(1+\mathbf j)\).
  • \((1+\mathbf j)(1+\mathbf i)\).

Discuss: Can \(\mathbb H\) be a field?

Multiplicative Inverses in \(\mathbb H\)

Notice that

\[ (a+b\mathbf i+c\mathbf j+d\mathbf k) (a-b\mathbf i-c\mathbf j-d\mathbf k) =a^2+b^2+c^2+d^2. \]

This element can be zero only if \(a,b,c,d\) are all zero.

Thus, for \(q=a+b\mathbf i+c\mathbf j+d\mathbf k\neq0\),

\[ q^{-1}=\frac{a-b\mathbf i-c\mathbf j-d\mathbf k}{a^2+b^2+c^2+d^2}. \]

Hence \(\mathbb H\) is a noncommutative division ring.

Try it: Find \((1+\mathbf i)^{-1}\).
