Definition of a Group

A group \((G,\circ)\) is a set \(G\) together with a law of composition \((a,b)\mapsto a\circ b\) satisfying:

  1. Associativity:
    \((a\circ b)\circ c=a\circ(b\circ c)\) for \(a,b,c\in G\).

  2. Identity:
    There exists \(e\in G\) such that \(e\circ a=a\circ e=a\) for every \(a\in G\).

  3. Inverses:
    For each \(a\in G\), there exists \(a^{-1}\in G\) such that \(a\circ a^{-1}=a^{-1}\circ a=e\).

Additional Definitions

A group is abelian (or commutative) if \(a\circ b=b\circ a\) for all \(a,b\in G\).

A Cayley table is a table that shows the result of the group operation for all pairs of elements in the group. We use it to verify that every element has an inverse. If the Caley table is symmetric about the diagonal, then the group is abelian.

The order of a group is the number of elements in the group. Groups can be finite or infinite.

Integers are a Group

Consider \((\mathbb Z,+)\).

  • The sum of two integers is an integer.
  • Addition is associative: \((m+n)+k=m+(n+k)\).
  • The identity is \(0\): \(0+n=n+0=n\).
  • The inverse of \(n\) is \(-n\): \(n+(-n)=(-n)+n=0\).

Since \(m+n=n+m\), \((\mathbb Z,+)\) is an abelian group.

\(\mathbb Z_n\) is a Group Under Addition

The integers mod \(n\) form a group under addition modulo \(n\).

The identity is \(0\), and every element has an additive inverse.

For example in \(\mathbb Z_5\),

\([2]+[3]=[3+2]=[0]\). In general, \([n]+[n-5]=[n-5]+[n]=[0]\).

\([m]+[n]=[n]+[m]\) so \((\mathbb Z_n,+)\) is an abelian group.

The Units \(U(n)\) are a Group Under Multiplication

Define \(U(n)=\{k\in\mathbb Z_n:\gcd(k,n)=1\}\). This is the group of units of \(\mathbb Z_n\)

For example, \(U(8)=\{1,3,5,7\}\).

Matrix Groups

Let \(M_2(\mathbb R)\) denote the set of all \(2\times 2\) matrices with entries from the real numbers.

The general linear group \(GL_2(\mathbb R)\) is the set of invertible matrices in \(M_2(\mathbb R)\).

The identity is the \(2\times 2\) identity matrix.

For \(A=\begin{pmatrix}a & b \\ c & d\end{pmatrix}\in GL_2(\mathbb R)\), the inverse is

\(A^{-1}=\dfrac{1}{ad-bc}\begin{pmatrix}d & -b \\ -c & a\end{pmatrix}\).

More Matrix Groups

If we change what numbers we allow in the entries of the matrices, we can get different groups. For example, if we only allow elements of \(\mathbb Z_3\), then we get the group \(GL_2(\mathbb Z_3)\).

The orthonormal group \(O_2(\mathbb R)\) is the set of matrices in \(GL_2(\mathbb R)\) with determinant equal to \(\pm1\).

The special linear group with entries in \(\mathbb R\) \(SL_2(\mathbb R)\) is the set of matrices in \(GL_2(\mathbb R)\) with determinant equal to \(1\).

Quaternion Group

Let

\(E=\begin{pmatrix}1&0\\0&1\end{pmatrix}\), \(I=\begin{pmatrix}0&1\\-1&0\end{pmatrix}\),

\(J=\begin{pmatrix}0&i\\i&0\end{pmatrix}\), \(K=\begin{pmatrix}i&0\\0&-i\end{pmatrix}\),

\(Q=\{E, -E, I, -I, J, -J, K, -K \}\), where \(i^2=-1\) and \(-E\) is \(-1 \cdot E\).

Group of Complex Numbers Under Multiplication

Let \(\mathbb C^\ast\) be the set of nonzero complex numbers.

Under multiplication, \(\mathbb C^\ast\) forms a group.

  • Identity: \(1\).

  • If \(z=a+bi\ne0\), then

    \(z^{-1}=\dfrac{a-bi}{a^2+b^2}\).

Thus every nonzero complex number has a multiplicative inverse.

The group \(\mathbb C^\ast\) is abelian.

Proposition 3.2.10 — Uniqueness of Identity

The identity element in a group \(G\) is unique.

Suppose \(e\) and \(e'\) are both identity elements.

Since \(e\) is an identity, \(ee'=e'\).

Since \(e'\) is an identity, \(ee'=e\).

Therefore, \(e=ee'=e'\).

Proposition 3.2.11 — Uniqueness of the Inverse

If \(g\) is any element in a group \(G\), then its inverse \(g^{-1}\) is unique.

Suppose \(g'\) and \(g''\) are both inverses of \(g\).

Then \(gg'=g'g=e\) and \(gg''=g''g=e\).

Therefore, \(g'=g'e=g'(gg'')=(g'g)g''=eg''=g''\).

Proposition 3.2.12 — Inverse of a Product

Let \(G\) be a group. If \(a,b\in G\), then \((ab)^{-1}=b^{-1}a^{-1}\).

Indeed,

\(abb^{-1}a^{-1} =aea^{-1} =aa^{-1} =e\),

and similarly,

\(b^{-1}a^{-1}ab=e\).

Thus \(b^{-1}a^{-1}\) is the inverse of \(ab\).

Proposition 3.2.13 — Inverse of an Inverse

Let \(G\) be a group. For any \(a\in G\), \((a^{-1})^{-1}=a\).

Since

\(a^{-1}(a^{-1})^{-1}=e\),

we obtain

\((a^{-1})^{-1} =e(a^{-1})^{-1} =aa^{-1}(a^{-1})^{-1} =ae =a\).

Proposition 3.2.14

Let \(G\) be a group and let \(a,b\in G\). Then the equations \(ax=b\) and \(xa=b\) have unique solutions in \(G\).

For \(ax=b\),

\(x=a^{-1}b\).

For \(xa=b\),

\(x=ba^{-1}\).

Proposition 3.2.15

If \(G\) is a group and \(a,b,c\in G\), then

\(ba=ca\quad\Longrightarrow\quad b=c\)

and

\(ab=ac\quad\Longrightarrow\quad b=c\).

These are the right and left cancellation laws for groups.

For example,

\(ba=ca \quad\Longrightarrow\quad baa^{-1}=caa^{-1} \quad\Longrightarrow\quad b=c\).

Defining Exponents

For \(g\in G\), define

\(g^0=e\),

\(g^n=\underbrace{g\cdot g\cdots g}_{n\text{ times}}\),

and

\(g^{-n}=\underbrace{g^{-1}\cdot g^{-1}\cdots g^{-1}}_{n\text{ times}}\).

Theorem 3.2.16

For all \(g,h\in G\),

  1. \(g^m g^n=g^{m+n}\) for all \(m,n\in\mathbb Z\);

  2. \((g^m)^n=g^{mn}\) for all \(m,n\in\mathbb Z\);

  3. \((gh)^n=(h^{-1}g^{-1})^{-n}\) for all \(n\in\mathbb Z\).

Furthermore, if \(G\) is abelian,

\((gh)^n=g^nh^n\).
